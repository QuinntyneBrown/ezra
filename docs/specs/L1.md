# L1 - High-Level Requirements

## L1-001: Installable cross-platform CLI
Ezra shall be a command-line tool that installs and updates as a .NET tool and runs the same way on Windows, macOS and Linux.

## L1-002: Hierarchical command model
Ezra shall expose its capabilities as root commands with nested subcommands (in the style of `dotnet ef migrations add`), so that hundreds of commands remain discoverable and consistent.

## L1-003: Modular, extensible tool architecture
Ezra shall be composed of independent tool modules (such as `Ezra.Scaffold`) that the root `ezra` command orchestrates. New tools shall be addable without changing existing tools, and every tool shall follow one shared contract so the codebase stays maintainable as it grows.

## L1-004: Consistent user experience
Every command shall behave consistently: help, argument validation, error reporting, exit codes and output verbosity work the same way across all tools.

## L1-005: Project scaffolding
Ezra shall scaffold a new project, named by the user, that is ready for AI-agent-assisted development: it includes an `AGENTS.md`, a `CLAUDE.md` pointing to it, and the skills installed locally on the user's machine.

## L1-006: Security
Ezra shall never write outside the location the user asked for, never overwrite the user's work without explicit consent, and never execute content it copies.

## L1-007: Performance
Ezra shall start and complete everyday commands fast enough to feel instant at the terminal, regardless of how many tools are installed.
