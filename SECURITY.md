# Security Policy

## Supported versions

Ezra is in early development. Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Report them privately using [GitHub private vulnerability reporting](https://github.com/quinntynebrown/ezra/security/advisories/new), or by email to quinntynebrown@gmail.com.

Include as much of the following as you can:

- The type of issue and the affected command or component
- Steps to reproduce, including the Ezra version and your OS
- The impact and how an attacker might exploit it

You can expect an acknowledgement within a few days. We will keep you informed as we investigate and ask that you give us reasonable time to fix the issue before disclosing it publicly.
